# Git Intro

## 📘 Description
Ce repository a été créé dans le cadre de ma formation à **Holberton School** afin de découvrir et pratiquer les bases de **Git** et du travail avec des branches.

L’objectif principal est de comprendre le fonctionnement du versionnement de code, la gestion des branches et la résolution de conflits simples.

---

## 🎯 Objectifs pédagogiques
- Initialiser un dépôt Git
- Ajouter et suivre des fichiers avec `git add`
- Valider des changements avec `git commit`
- Créer et utiliser des branches (`git branch`, `git checkout`)
- Fusionner des branches avec `git merge`
- Comprendre les conflits simples entre branches
- Utiliser `git push` pour envoyer le code sur GitHub

---

## 📂 Contenu du repository
Ce repository contient des fichiers texte simples utilisés uniquement pour tester les fonctionnalités de Git, notamment :
- des modifications effectuées sur différentes branches
- des messages distincts provenant de la branche principale (`main`) et d’une branche secondaire (`feature branch`)
- des changements volontairement conflictuels pour observer le comportement de Git lors d’un merge

Exemples de contenus utilisés :
- Messages provenant d’une branche de fonctionnalité
- Changements parallèles entre `main` et une branche secondaire

---

## 🔀 Concepts Git abordés
- Branches (`main`, `feature branch`)
- Commits
- Merge
- Gestion de modifications concurrentes
- Historique Git

---

## ▶️ Utilisation
Ce projet n’a pas vocation à être exécuté.

Il sert uniquement de **support pédagogique** pour manipuler Git en ligne de commande et comprendre son fonctionnement.
